# DESIGN SYSTEM - SPORTIVA24

## Filosofía

Sportiva24 debe sentirse como una plataforma tecnológica de inteligencia deportiva.

No debe parecer una casa de apuestas.

No debe parecer una página de tipsters.

Debe transmitir confianza, precisión y profesionalismo.

---

- Nike

- ESPN

## Experiencia de usuario

El usuario debe encontrar información útil en menos de 5 segundos.

Cada pantalla debe responder:

¿Qué está pasando hoy?

¿Qué partido me interesa?

¿Por qué?

¿Qué información tengo para decidir?

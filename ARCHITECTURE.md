# ARCHITECTURE - SPORTIVA24

## Objetivo

Construir una plataforma escalable, mantenible y modular.

---

## Tecnologías

Frontend

- Next.js 16
- React
- TypeScript
- Tailwind CSS

Backend

- Supabase (futuro)

Hosting

- Vercel

---

## Estructura

app/

Páginas de la aplicación.

components/

Componentes reutilizables.

public/

Imágenes e iconos.

docs/

Documentación del proyecto.

lib/

Funciones compartidas.

hooks/

Hooks personalizados.

services/

Conexión con APIs.

types/

Tipos de TypeScript.

---

## Reglas

No duplicar componentes.

No escribir lógica repetida.

Todo debe ser reutilizable.

Cada componente debe tener una única responsabilidad.

---

## Componentes

Cada componente debe ser pequeño.

Fácil de leer.

Fácil de mantener.

---

## Filosofía

La arquitectura debe facilitar el crecimiento del proyecto durante los próximos años.

Nunca sacrificar calidad por velocidad.
